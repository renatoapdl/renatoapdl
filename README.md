Sou engenheiro eletricista e, há mais de 14 anos, garanto a confiabilidade e a disponibilidade de
sistemas críticos do Rádio Observatório Espacial do Nordeste (Mackenzie/NASA): monitoramento de
telemetria, dashboards de performance (Grafana, MTTR, SLA) e relatórios técnicos em inglês para a
rede global IVS-NASA.

Estou em transição ativa para Engenharia de Dados e aplico ao ciclo de dados a mesma mentalidade de
confiabilidade que aprendi na operação: construo pipelines ETL com Python e PySpark, modelo dados
com SQL e transformo fontes reais em informação estruturada.

### O que estou desenvolvendo agora

- pipelines ETL com validação e testes automatizados (pytest)
- tratamento e qualidade de dados em Databricks com Spark SQL
- arquitetura de dados em camadas (bronze/prata/ouro)
- ingestão de dados em tempo real via API REST/JSON
